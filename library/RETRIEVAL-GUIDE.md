# 选图与检索方法

先从书籍材料提出视觉问题，再找能回答该问题的海报。库中的概念标签是可迁移机制，不是书籍题材分类，也不替用户决定设计方向。

## 从叙事到查询

1. 从书籍内容关系、具体物象与材料可能性分别提出查询，比较视觉路线后再确定构图。主题词不是固定图形指令。
2. 探索阶段使用 OR、`--diverse` 和本任务稳定 `--seed`，查看 `matched_terms`、`missing_terms` 与图片。四张是最终展示名单，不是探索上限；候选不足时如实报告缺口。
3. 必须共同满足的词用 `--match all`；确定的构图、主导媒介、流派关系用独立筛选。结果可能少于四张或为空，不以弱匹配冒充共同满足。
4. 分别跑几条视觉路线，再合并去重和看图，比把所有要求塞进一个宽泛 OR 查询更有效。具体选例理由保存在书籍任务中，不回写成原作事实。

```powershell
# 在库根目录运行；Python 为本机可用的 Python 3
python tools/library.py search --query '秩序 聚合' --diverse --limit 12
python tools/library.py search --query '瑞士主义 几何' --match all --limit 8
python tools/library.py search --history surrealism --relation visual_affinity --composition centered --limit 8
python tools/library.py search --family expressive_type --composition diagonal --status reviewed --limit 8
```

## 匹配与排序合同

- 默认 `--match any`：任一词命中；`all`：每个词均命中。中英文别名按完整词组匹配、去重；连续中文仅在全部片段均为已知别名时拆分。未知长词保持完整。艺术史、构图等受控词只查结构化字段，备注中的否定句不会触发它们。
- 自由文本查作品名、作者、年份、原题材、视觉分析及概念理由。不是全文语义搜索，不自动理解整本书；书名可能没有任何直接结果。
- 同一筛选维度中的多个值取 OR，不同维度取 AND。流派与关系必须出现在同一条艺术史记录里。
- 先按每张图的命中词数，再按字段权重排序。`--diverse` 在同一命中数量组内先补足尚未覆盖的查询词，再按字段权重、作者/视觉路线/构图重复程度排序。同等相关的结果以使用上下文、seed 与来源身份哈希决胜，避免 ID 越小越靠前；同一输入可复现，改变 seed 只探索同等相关候选。得分不是美感、版权或适书程度评分。
- `matched_terms`、`missing_terms`、`matched_fields` 解释部分命中。多样性不保证四个互斥流派或四位不同作者；稀缺条件应保留稀缺结果。
- 网页与 CLI 引擎传入相同上下文时使用同一规则；网页默认无 seed、无持久使用历史，不能自动读取 CLI 账本。网页可在每个维度选择一个值，CLI 的 history/relation/composition/concept 可重复传入。

## 近期使用

`search --usage-ledger <JSONL> --recent-tasks 20 --seed <task-id>` 读取使用事实，`--batch-ids <ID...>` 标注同批已选参考；均为软降权，不排除作品。`--history` 仍然是艺术史筛选。结果解释近期展示、实际使用、同批重复、构图标签交集及上下文分数。标签重叠不是骨架相同的证明，最终仍要看图比较。

`record-usage --usage-ledger <JSONL> --event <JSON>` 显式记录事件；搜索只读。事件包含 `event_id`、`task_id`、带时区的 `timestamp`、`shown_ids`、`used_ids`，可附 `route_skeletons`（route_id/reference_ids/description）和 note。同一任务去重计数，同事件重试幂等，冲突报错。并行分支由协调者单写；文件缺失视为空历史，格式错误报错。使用事实不代表审美偏好。

## 分类时最容易混淆的边界

| 边界 | 判定方法 |
|---|---|
| 历史归属 / 视觉近似 | 归属与影响需要可定位证据及作品/作者层级；仅看外观用 visual_affinity，证据不足允许空值。 |
| 插画 / 摄影 / 拼贴 / 材质 | 识别画面主要组织手段，不按“彩色印刷”统一归为插画。照片再现、拼合、网点、折叠等分别记录。 |
| 几何 / 符号 / 图解 | 比例与几何规则、一个凝练物象、解释关系的图式是不同机制；可用主辅路线表达交集。 |
| 原题材 / 可迁移概念 | 古堡不自动等于记忆；人物特写不自动等于亲近；“知识”字样不自动等于探索。概念必须说明画面如何产生该关系。 |
| 文字密度 | 观察实际阅读负担：孤立标题、标题加短信息、连续段落/密集日程。不能因为字号小就判定高密度。 |
| 原作 / 再现 | 馆藏照片若只记录街头广告被涂改的现场，不作为设计作品入库。完整且身份可核对的历史海报复制图可以入库，并注明复制媒介。 |

不要求每张都填流派或三个概念。标签上限用于减少检索噪声，不限制创作。

## 取图与维护

```powershell
python tools/library.py stage --ids P-0007 P-0117 P-0250 P-0295 --dest '../../book-task/references'
```

目标须为库外的新目录；已有目录不覆盖。暂存保留预览图原始字节、顺序、完整元数据和 SHA256，不裁切、不生成集合图。预览不等于印刷母版，`user_decision` 仍为空。

修改唯一来源 `cases/<ID>/case.json` 后运行 validate、build。`reviewed` 必须有日期、复核者、来源核对、看图依据、来源链接和匹配当前图片的哈希；图片变更会使旧复核失效。该标记代表来源/标注复核，不代表用户的审美选择或公共再利用许可。

新增主题材料（画作、照片、地图、走势图）按书籍任务在线检索，存该任务的 materials/，不无限扩展本海报库。
