# PhotoCraft 原生制作与精修

用于用户要求 PC/PhotoCraft、可编辑重建，或已选择原生排版与真实素材合成的任务。仅生成概念稿不必读取。应用能力、命令参数和路径范围以当前工具说明为准。

## 找到当前文件与编辑对象

先从任务记录和实际文件确定当前母版，查看全图；打开后检查文档身份、画布、图层与文本。当前活动窗口不一定是目标文档。用 doc_open/doc_inspect 及当前可用的会话工具确认，按 command_list 发现需要的命令，再调用 command_run/command_batch；不要照搬旧任务的图层 ID 或版本专属参数。

接续编辑先另存新版本，保留已认可母版。明确修改对象及保留项，检查分组、链接、裁切、蒙版、变换和效果。不得关闭或覆盖无关的用户文档。

## 以可修改的结构实现

| 对象 | 适用结构与承诺边界 |
| --- | --- |
| 书名、作者、说明等普通文字 | 原生文字层，核字体实际加载与换行；可重新输入 |
| 手工花饰或定制字形 | 矢量形状/路径；可修改轮廓、位置、填色，不宣称可直接键入另一个词 |
| 照片、画作与局部 | 保留源图，裁切与独立蒙版；可替换、调位置与遮罩，不等于像素内部每个物体都可独立编辑 |
| 数值字形、图表等嵌入对象 | 保留源数据与生成依据；对象可替换，内部编辑能力取决于实际格式 |

图层按需要修改的对象划分，合理命名和分组；分层数量不作为质量指标。用户给 JPG 要求重建时，先分辨可直接恢复与需重新绘制的部分，沿用原设计并说明重建差异；导入整张 JPG 只是参考层，不能称完成可编辑重建。

需要原作精确细节时从同一源图提取片段，保持一致的缩放、位置与裁切关系。优先独立蒙版实现擦除、局部灰度或渐变处理，保留回改能力。文字、真实数据与图像分开，避免整图重绘引入数值或身份变化。

## 局部编辑与依赖

修改前检查受影响的关系，修改后一起核对。例如：
- 移动或换字后，贴合旧字形的叠印蒙版可能需要重算。
- 反色/双色分界随背景位置变化，不能只移动文字而留下旧色标位置。
- 放大原画后，与其局部对应的缺口、框线、连线和源图变换要同步。
- 字号变化后检查换行、栏宽、基线、符号、负号和小数点。

一次修改只展开实际有关的依赖；用户只要求页脚移位时直接完成，不重启研究、四图筛选或全图生成。支持可逆隐藏的删除可先隐藏，但交付应确认导出确实没有该内容。

## 保存与验证

查看修改后的全图和必要局部，核对请求是否落实、无关区域是否受损。精确局部编辑可比较修改前后差异范围；字体替换、渲染差异等导致像素变化时解释原因，不把差异图当作审美评分。

保存原生文件并导出预览；交付可编辑文件前，重开所保存的文件，检查文字/形状/蒙版是否仍在、字体与版面是否一致，再导出比较。相同渲染条件下可作像素比较；无法重开或无法验证的能力明确标为未验证，不写“已通过”。普通 PNG 扁平导出与原生文件保留图层是不同交付。

连接或命令失败时保留现有文件，发现当前能力后选择可用操作；不要在 Skill 中固化端口、凭据、启动参数或历史故障绕路。无法完成原生操作时交付能确认的部分和具体缺口，不假称 PC 已更新。用户可用文件、用途和归档说明见 [delivery.md](delivery.md)。
